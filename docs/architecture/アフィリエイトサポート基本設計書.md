## 3. 機能要件

### 3.1 機能一覧

| No. | 機能名 | 概要 | 関連画面 |
| --- | --- | --- | --- |
| F-01 | ログイン | アカウント・パスワードで認証し、作品一覧画面へ遷移する | ログイン画面 |
| F-02 | アカウント登録画面への遷移 | ログイン画面のリンクからアカウント登録画面へ遷移する | ログイン画面 |
| F-03 | 作品一覧表示 | 作品情報をカード形式で一覧表示する（画面表示時は全作品を取得） | 作品一覧画面 |
| F-04 | 作品検索 | 女優名・メーカー・ジャンル・2D/VRの条件で作品を絞り込む | 作品一覧画面 |
| F-05 | 検索条件クリア | 全検索条件をクリアし、ページ番号を1にする | 作品一覧画面 |
| F-06 | 表示数変更 | 1ページの最大表示数を切り替える（20 / 40 / 60） | 作品一覧画面 |
| F-07 | ページング | 作品数が最大表示数を超える場合にページ単位で切り替える | 作品一覧画面 |
| F-08 | 女優名リンク検索 | 作品情報カードの女優名リンクから、その女優名で自動検索する | 作品一覧画面 |
| F-09 | X投稿文作成 | 作品情報から投稿文をAPIで生成し、ダイアログに表示する | 作品一覧画面 |
| F-10 | X投稿 | 確認ダイアログで投稿文を確認・編集のうえ、Xへ投稿する | 作品一覧画面 |
| F-11 | 投稿文コピー | 表示した投稿文をクリップボードへコピーする | 作品一覧画面 |
| F-12 | ログアウト | ヘッダーのログアウトボタンからログアウトする（詳細は今後検討） | 共通 |
| F-13 | サイドメニュー操作 | サイドメニューの表示/非表示切替、各画面への遷移 | 共通 |

### 3.2 機能概要

#### 3.2.1 ログイン（F-01, F-02）

- アカウントとパスワードを入力し、ログインボタン押下で認証する。
- 認証後、作品一覧画面に遷移する。
- ログイン画面からアカウント登録画面へ遷移するリンクを設ける。

#### 3.2.2 作品の一覧表示・検索（F-03 〜 F-08）

- 作品一覧画面の表示時は全作品を取得して表示する。
- 検索条件は「女優名」「メーカー」「ジャンル」「2D/VR」。
- 検索条件を入力せずに検索ボタンを押下した場合は、全作品を表示する。
- 検索結果が0件の場合は「該当する作品がありません。検索条件を変更してください。」を表示する。
- 検索実行後は1ページ目を表示する。
- クリアボタン押下で全検索条件を初期状態に戻し、ページ番号を1にする。
- 1ページの最大表示数は20 / 40 / 60から選択可能（初期値20）。
- 作品情報カードの女優名リンク押下で、検索パネルの女優名にその名前が自動入力され、検索が自動実行される。

#### 3.2.3 X投稿（F-09 〜 F-11）

1. 作品情報カードのXボタンを押下する。
2. 投稿文作成APIを実行し、完了後にダイアログを表示する。
3. ダイアログに投稿文（APIで生成した投稿文＋リンク）を表示する。投稿文は編集可能。
4. 投稿ボタン押下でXに投稿する。
5. 成功時は「Xに投稿しました。」、失敗時は「投稿に失敗しました。」を表示する。
6. 投稿完了までダイアログを表示し続ける。
7. コピーボタン押下で投稿文をクリップボードへコピーし、トーストで通知する。

## 4. 非機能要件

### 4.1 画面・操作性

| No. | 要件 |
| --- | --- |
| NF-01 | 画面はレスポンシブとし、画面サイズに応じて画面内の構成を柔軟に変化させる。 |
| NF-02 | 検索条件フィールドは横並びで表示し、横並びにできない場合は改行する（MUI `Grid` のブレイクポイントで制御）。 |
| NF-03 | アカウント・パスワードのテキストボックスは半角入力のみとする。その他のテキストボックスは全角・半角ともに入力可能とする。 |
| NF-04 | 作品名が長い場合は末尾を「...」で省略し、ツールチップで全文を表示する。 |

### 4.2 性能・応答

| No. | 要件 |
| --- | --- |
| NF-05 | 検索など情報の取得に時間がかかる場合、ローディングダイアログを表示する。 |
| NF-06 | ローディングダイアログは外側押下で閉じず、取得完了まで閉じられない。 |
| NF-07 | 連打対策として、API実行中は検索ボタン・投稿ボタンを `disabled` にする。 |

> **要確認**：ローディングダイアログの表示閾値が「共通」仕様では「1秒以上」、「ローディングダイアログ」コンポーネント仕様では「500ms超」と記載されている。また、投稿時も「500ms以上」とされている。閾値の統一が必要（本書ではコンポーネント仕様の500msを暫定採用）。

### 4.3 エラーハンドリング

| No. | 要件 |
| --- | --- |
| NF-08 | API実行失敗時はエラーダイアログに「システムエラーが発生しました。」を表示する。 |
| NF-09 | X投稿の成否はトースト（成功/失敗）および画面メッセージで通知する。 |
| NF-10 | 各種通知（コピー完了、投稿成功、投稿失敗、警告）はトーストで表示する。 |

### 4.4 保守性・設計方針

| No. | 要件 |
| --- | --- |
| NF-11 | UIコンポーネントは責務ごとに分離する。リンクなどに別の責務を持たせる場合は別コンポーネントとして定義する。 |
| NF-12 | ボタンはPropsで関数を受け取り、実行内容を関数で可変にする。 |
| NF-13 | プルダウンメニューの選択肢はDBのマスターテーブルから取得し、hooks（API）経由でPropsとして渡す。 |
| NF-14 | 入力制限（半角のみ／全角半角可）の切替は `utils` 関数で行う。 |
| NF-15 | UIライブラリにはMUI（Material UI）を使用し、ページングはMUI標準の `<Pagination />` を使う。 |

### 6.7 検索条件フィールド（SearchFilterField）

| 項目 | 内容 |
| --- | --- |
| 役割 | ラベル＋入力コントロールを1組にしたコンポーネント |
| 構成 | ラベル（`label`）＋ 入力コントロール（`children`） |
| 入力コントロール | テキストボックス、プルダウンメニューなど |

**実装例**

```tsx
import React from 'react';
import { FormControl, FormLabel, Box } from '@mui/material';

type SearchFilterFieldProps = {
  label: string;
  children: React.ReactNode;
};

export const SearchFilterField: React.FC<SearchFilterFieldProps> = ({ label, children }) => {
  return (
    // fullWidthで幅を広げやすくし、下部に余白を持たせる
    <FormControl fullWidth sx={{ mb: 2 }}>
      {/* ラベルのスタイル（文字サイズや色など）を調整 */}
      <FormLabel sx={{ mb: 1, fontSize: '0.875rem', fontWeight: 'bold' }}>
        {label}
      </FormLabel>
      <Box className="control-wrapper">
        {children}
      </Box>
    </FormControl>
  );
};
```

### 6.8 検索パネル

複数の検索条件フィールドを1つにまとめたコンポーネント。

#### 構成

| 項目 | 種別 |
| --- | --- |
| 女優名 | テキストボックス |
| メーカー | プルダウンメニュー |
| ジャンル | テキストボックス |
| 2D/VR | プルダウンメニュー |
| クリアボタン | ボタン |
| 検索ボタン | ボタン |

#### 仕様

- 検索ボタン押下で検索を実行する。
- 検索実行後は1ページ目を表示する。
- 検索ボタンの連打対策として、API実行中は検索ボタンを `disabled` にする。
- プルダウンメニューの初期値は「すべて」、テキストボックスの初期値は空文字とする。

#### 配置

- 基本は横並び、はみ出る場合は改行する。
- 配置順：検索内容 → クリアボタン → 検索ボタン
- 実装：`<Grid container spacing={2}>` を使い、各フィールドに `<Grid size={{ xs: 12, sm: 6, md: 3 }}>` のようにブレイクポイントを指定する。

### 6.9 作品情報カード

#### 構成

| 項目 | 種別 | 備考 |
| --- | --- | --- |
| 作品画像 | 画像 | |
| 作品名 | ラベル | 長い場合は末尾を「...」とし、ツールチップで全文表示 |
| 女優名 | リンク（[女優検索リンク](#66-女優検索リンク)） | 押下で女優名検索を自動実行 |
| Xボタン | ボタン | 押下で投稿文作成APIを実行し、確認ダイアログを表示 |
| 投稿文作成ボタン | ボタン | 押下でダイアログを表示し、投稿文（APIで生成した投稿文＋リンク）を表示 |

#### 配置

- 上半分：作品画像
- 下半分（上から順に）：
  1. 作品名
  2. 女優名
  3. Xボタン ＋ 投稿文作成ボタン

#### Xボタン押下時のフロー

1. 投稿文作成APIを実行する。
2. 確認ダイアログを表示する。
3. ダイアログに投稿文を表示する。

#### 確認ダイアログ（X投稿）

| 項目 | 内容 |
| --- | --- |
| 役割 | Xの投稿文を確認し、投稿する |
| 投稿文 | 表示・編集可能 |
| 投稿ボタン | 押下でXに投稿する。連打対策として `disabled` にする |
| 閉じる | 右上の×ボタン |
| 投稿成功時 | 「Xに投稿しました。」を表示 |
| 投稿失敗時 | 「投稿に失敗しました。」を表示 |
| 表示継続 | 投稿完了までダイアログを表示し続ける（500ms以上かかる場合はローディングダイアログを表示） |

### 6.10 一覧表示パネル

作品情報カードを並べて表示するパネル。

#### 仕様

- 作品情報カードを並べて表示する。
- 1ページの最大表示数は未確定（暫定で20）。
- 最大表示数は画面上で変更可能とし、候補は 20 / 40 / 60（初期値20）とする。
- 表示する作品数が最大表示数より多い場合は、ページングで切り替える。
- ページングはMUI標準の `<Pagination />` を使用する。
- 5ページ以降は「...」で省略する（例：5ページ目表示時は `1 2 3 4 5 ... 20`）。
- 「＜」「＞」ボタンでページ変更を可能にする。

#### 配置

- パネル上部に以下を横並びで表示する。
  - 最大表示数変更
  - ページング

### 6.12 サイドメニュー

| 項目 | 内容 |

| 動作 | ボタン押下で各画面に遷移する |

### 6.13 ローディングダイアログ

| 項目 | 内容 |
| --- | --- |
| 表示条件 | 処理が500msを超えた場合に表示する（※閾値は[4.2](#42-性能応答)の要確認事項を参照） |
| 外側押下 | 押下しても閉じない |
| 閉じ方 | 取得完了まで閉じることができない |

### 6.14 ダイアログ

| 項目 | 内容 |
| --- | --- |
| 閉じ方 | 右上の×ボタンで閉じる |
| 投稿文表示時 | コピーボタンも表示する |
| コピーボタン | 押下でクリップボードにコピーし、成功時はトーストで「クリップボードにコピーしました」と表示する |

### 6.15 エラーダイアログ

| 項目 | 内容 |
| --- | --- |
| 表示条件 | API実行失敗時 |
| 表示内容 | 「システムエラーが発生しました。」 |
| 閉じ方 | 右上の×ボタンで閉じる |

### 6.16 確認ダイアログ

| 項目 | 内容 |
| --- | --- |
| 用途 | Xに投稿する前の確認などで表示する |
| 閉じ方 | 右上の×ボタンで閉じる |
| ボタン | 押下で渡された関数を呼び出して実行する |

### 6.17 トースト

| 種別 | 用途 |
| --- | --- |
| 通知 | コピー完了など |
| 成功 | 投稿成功など |
| 失敗 | 投稿失敗など |
| 警告 | 必要に応じて使用 |
